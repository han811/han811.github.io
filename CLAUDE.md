# Project notes for Claude

Personal website (Jekyll, built by GitHub Pages). Keep the repo minimal; add files only when a feature needs them.

## Writing rules

Apply to every piece of text written in this repo: site copy, project pages, blog posts, README, commit messages.

1. Do not overstate facts as "pivotal," "lasting," or "turning points."
2. Avoid vague significance claims unless sources support them.
3. Avoid promotional words like "vibrant," "renowned," or "groundbreaking."
4. Avoid AI-style fillers like "delve," "robust," and "landscape."
5. Prefer concrete facts over generalities.
6. Do not invent citations, URLs, DOIs, ISBNs, pages, or sources.
7. Cite only checked sources that support the claim.
8. Do not leave placeholders or unfinished references.
9. Keep formatting simple.
10. Use the right markup: Markdown, wikitext, HTML, LaTeX, etc.
11. Avoid canned three-part phrasing.
12. Do NOT EVER use em dashes.
13. Remove chatbot phrases like "As an AI."
14. Show accuracy and neutrality; do not merely claim them.
15. Verify instead of sounding confident.
16. State uncertainty when evidence is limited.
17. Do not treat AI detectors as proof.
18. Optimize for usefulness, specificity, sourcing, neutrality, and reviewability.
