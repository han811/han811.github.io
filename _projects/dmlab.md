<h3>Projects</h3>
My work as an R&D Intern at DMLab centered on two main projects: real-time object detection and chatbot development.

For the real-time object detection project, I implemented a system using the Google Coral hardware accelerator. This involved converting the SSD (Single Shot MultiBox Detector) algorithm to a tflite model to enable efficient, real-time performance on the hardware.
